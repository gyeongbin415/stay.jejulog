D. 추적 이벤트 · 테스트 점수 규칙

추적 방식

모든 클릭 요소에는 data-track 이름표가 붙어 있고, 클릭하면 window.dataLayer에 { event: 'click', track: '이름표' }가 쌓입니다 (GA4 · GTM 연결 시 그대로 수집). 클릭 외 행동은 아래 이벤트로 기록합니다.

결과 유형 = 성향 점수 합계 최고. 동점 규칙 ① 마지막 문항(Q7)에서 고른 선택지의 주 성향 ② Q6 → Q1 순으로 거슬러 올라가며 동점 유형을 가리킨 첫 답 ③ 고정 순서 수집가 → 기록자 → 장면 → 모험.
대표 프로그램 = 결과 유형의 프로그램 중 프로그램 점수 최고(동점 시 유형 목록 순서). 보조 추천 = 같은 유형의 나머지 + 점수를 받은 다음 순위 유형의 최고 프로그램(최대 2개, 점수 0인 유형은 제외).
검증: 가능한 16,384개 답변 조합(4의 7제곱) 전수 계산 — 유형 분포 모험 4,212 · 수집 3,677 · 기록자 4,513 · 장면 3,982, 9개 프로그램 모두 대표 추천으로 등장 (대표 추천 분포: 와인 2,565 · LP 2,516 · 러닝 2,193 · 캠핑 2,019 · 공예 1,875 · 꽃 1,471 · 영화 1,417 · 집밥 1,167 · 책 1,161) (npm run test:quiz).
